# Isaac Levin Portfolio

A standalone React portfolio for [isaaclev.in](https://isaaclev.in), built with Vite and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The deployable static site is written to `dist/`. It can be hosted on any static host, including GitHub Pages, Vercel, Netlify, or Cloudflare Pages.

## Project structure

```text
src/
  App.tsx       Portfolio content and interactions
  main.tsx      React entry point
  styles.css    Complete visual system and responsive styles
public/
  projects/     Project imagery
  resume/       Downloadable résumé
  og.png        Social sharing image
index.html      Metadata and HTML entry point
```

This repository has no platform authentication, server runtime, database, or provider-specific hosting dependency.
